一、设计概述

基于 PRD V1.0（5/22更新）要求，将原有3层风险分级升级为7层精细用户分层体系，引入国际标准化功能评估量表，覆盖5个扩展维度。

部位参考量表原文献采纳维度

膝部IKDCIrrgang et al., 2001症状+运动活动+功能 简化5项
腰部ODIFairbank et al., 1980日常活动受限 简化5项
心理TSKKori et al., 1990恐惧回避信念 简化2项

四、分层算法（FPP 综合评分）

4.1 算法流程

Step 1: 硬排除 → L6 高风险 → 术后未获许可 → 结构性异常：畸形/严重肿胀/无法负重/无法主动抬臂 → 腰部特殊红旗：大小便异常/鞍区麻木/进行性无力 → 全身警示：发热+体重下降+夜间盗汗 → 神经症状：肌无力 + 疼痛≥7分 Step 2: 术后路径 → L5（需采集手术类型+术后天数） → 术后已获许可 Step 3: 计算 FPP (Function-Pain-Phase) 综合得分 pain_score = 疼痛程度(0-10) function_score = 功能5项总分/20 × 10 (0-10) duration_weight = { <1周:0.8, 1-2周:0.9, 2-6周:1.0, >6周:1.2, 反复:1.1 } FPP = pain_score × 0.5 + function_score × 0.5 × duration_weight Step 4: 功能受限等级 0-2分: 无受限 | 2-5分: 轻度 | 5-8分: 中度 | 8-10分: 重度 Step 5: 综合分层 pain=0 + function=0 → L0 FPP≤3 + 时间<2周 → L1 FPP≤3 + 时间≥2周 → L2 3<FPP≤6 + 受限∈[轻度,中度] → L3 FPP>6 或 受限=重度 → L4

题型：多选 | 必填

  • 膝关节
  • 腰部
  • 多部位不适
A2 请评估您当前的疼痛程度
题型：滑块 0-10 | 必填 | NPRS标准
  • 0 = 无痛 → 10 = 剧痛
A3 这种不适持续了多长时间？
题型：单选 | 必填 | 时间权重依据
  • 不到1周（急性期）— 权重0.8
  • 1-2周（急性后期）— 权重0.9
  • 2-6周（亚急性期）— 权重1.0
  • 超过6周（慢性期）— 权重1.2
  • 反复发作（时好时坏）— 权重1.1
A4 您的不适是怎么开始的？
题型：单选 | 必填 | 扩展维度：机制
  • 急性外伤（如摔倒、扭伤、碰撞）
  • 过度使用（如长时间重复动作、突然增加运动量）
  • 逐渐出现（没有明显诱因，慢慢加重）
  • 不明原因

七、模块C：红旗筛查（4-5题）

⚠️ 以下情况可能提示需要立即就医，请务必如实回答

通用红旗（肩/膝/腰均有）

C1 您是否接受过相关手术？
题型：单选 | 必填
  • 非术后
  • 术后，已获得医生/康复师运动许可
  • 术后，尚未获得运动许可 → 【高风险】禁止自行练习，请立即联系主刀医生
C2 是否出现以下神经症状？（可多选）
题型：多选 | 必填 | 每个选项均有就医指导
  • 无
  • 麻木或感觉减退 → 建议72小时内就医
  • 刺痛或电击样痛 → 建议72小时内就医
  • 肌肉无力 → 【警示】建议24小时内就医
  • 疼痛放射到四肢 → 建议1周内就医
C3 是否出现以下全身症状？（可多选）
题型：多选 | 必填 | 肿瘤/感染警示
  • 无
  • 发热或感染迹象
  • 不明原因体重下降
  • 夜间盗汗
  • 疼痛持续加重，休息不缓解
⚠️ 肿瘤警示 如同时出现 体重下降 + 夜间盗汗 + 休息不缓解 → 建议就医排查
C5 是否出现以下结构性异常？（可多选）
题型：多选 | 必填 | 每个选项均有紧急程度标识
  • 无
  • 明显畸形或关节脱位外观 → 【紧急】立即前往急诊/骨科
  • 急性严重肿胀 → 【紧急】建议24小时内就医
  • 无法负重行走/无法主动抬臂 → 【警示】建议24-48小时内就医

腰部特有红旗（仅腰部显示）

🚨 马尾综合征（Cauda Equina Syndrome）是骨科急症，如出现以下任何症状，请立即前往急诊就医！延误治疗可能导致永久性神经损伤。
C4 【🚨 紧急】是否出现以下马尾综合征警示症状？（可多选）
题型：多选 | 必填 | 骨科急症
  • 以上均无
  • 大小便异常（失禁或排尿困难）→ 【🚨 马尾综合征】立即前往急诊
  • 会阴/鞍区麻木 → 【🚨 马尾综合征】立即前往急诊
  • 下肢进行性无力 → 【紧急】建议24小时内就医
  • 严重外伤后剧痛
  • 发热/感染迹象
