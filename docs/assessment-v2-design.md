# 运动康复综合评估问卷 V2.0 设计文档

> 版本：V2.0  
> 日期：2026-05-21  
> 作者：AI Assistant  
> 适用范围：肩/膝/腰三个部位的运动康复自查

---

## 一、设计目标

### 1.1 核心目标

基于 PRD V1.0（5/22更新）的7层用户分层体系，设计一套**综合评估问卷**，实现：
- 从原有3层风险分级（高/中/低）升级为**7层精细用户分层**
- 引入**国际标准化功能评估量表**（SPADI/IKDC/ODI简化版）
- 覆盖**5个扩展维度**：部位、时间、机制、目标、转化意愿
- 支持**量化功能评分**和复评对比

### 1.2 参考量表

| 部位 | 参考量表 | 原文献 | 采纳维度 |
|------|---------|--------|---------|
| 肩部 | SPADI (Shoulder Pain and Disability Index) | Roach et al., 1991 | 疼痛+功能障碍各5项简化 |
| 膝部 | IKDC (International Knee Documentation Committee) | Irrgang et al., 2001 | 症状+运动活动+功能简化 |
| 腰部 | ODI (Oswestry Disability Index) | Fairbank et al., 1980 | 日常活动受限简化 |

## 二、7层用户分层体系

### 2.1 分层定义

| 层级 | 代码 | 名称 | 定义 | 处置策略 |
|------|------|------|------|----------|
| L0 | `asymptomatic` | 无症状 | 疼痛=0，功能评分=0 | 预防性动作+体态教育 |
| L1 | `mild_acute` | 轻症（急性早期） | FPP≤3，持续时间<2周，无红旗 | 居家康复+观察3-5天 |
| L2 | `chronic` | 慢性疼痛 | FPP≤3，持续时间≥2周，无红旗 | 结构化进阶方案 |
| L3 | `conservative` | 保守处理适配 | 3<FPP≤6，功能轻中度受限，无红旗 | 标准康复动作包 |
| L4 | `specialist` | 专科评估指征 | FPP>6 或 功能重度受限，无红旗 | 建议线下专科评估 |
| L5 | `post_op` | 术后康复期 | 已手术，获医生/康复师许可 | 术后专用渐进方案 |
| L6 | `high_risk` | 高风险排除 | 有红旗症状 或 术后未获许可 | 禁止自行练习，建议就医 |

### 2.2 分层算法

```
Step 1: 硬排除（L6 高风险）
  → 术后未获许可
  → 结构性异常：畸形/严重肿胀/无法负重/无法主动抬臂
  → 特殊红旗（腰部）：大小便异常/鞍区麻木/进行性无力
  → 全身警示：发热+体重下降+夜间盗汗
  → 神经症状：肌无力 + 疼痛≥7分

Step 2: 术后路径（L5）
  → 术后已获许可

Step 3: 计算 FPP (Function-Pain-Phase) 综合得分
  pain_score = 疼痛程度(0-10)
  function_score = 功能5项总分/20 × 10 (0-10)
  duration_weight = { <1周:0.8, 1-2周:0.9, 2-6周:1.0, >6周:1.2, 反复:1.1 }
  FPP = pain_score × 0.5 + function_score × 0.5 × duration_weight

Step 4: 功能受限等级
  0-2分: 无受限
  2-5分: 轻度受限
  5-8分: 中度受限
  8-10分: 重度受限

Step 5: 综合分层
  pain=0 + function=0 → L0
  FPP≤3 + 时间<2周 → L1
  FPP≤3 + 时间≥2周 → L2
  3<FPP≤6 + 受限∈[轻度,中度] → L3
  FPP>6 或 受限=重度 → L4
```

## 三、问卷模块设计

### 3.1 模块总览

| 模块 | 题目数 | 适用对象 | 说明 |
|------|--------|---------|------|
| A. 基础信息 | 4题 | 所有用户 | 部位+疼痛+时间+机制 |
| B. 功能评估 | 5题/部位 | 按A1选择显示 | 参考国际PROMs简化 |
| C. 红旗筛查 | 5题 | 所有用户 | 术后+神经+全身+特殊+结构 |
| D. 目标与转化 | 4题 | 所有用户 | 目标+运动水平+时间+付费意愿 |

**总计：18题（单部位），完成时间约4-5分钟**

### 3.2 动态显示逻辑

```
A1（部位选择）
  → 若选肩部：显示 B-S1~B-S5
  → 若选膝部：显示 B-K1~B-K5
  → 若选腰部：显示 B-L1~B-L5
  → 若选多部位：显示所有对应模块

C4（特殊红旗）
  → 仅当A1包含"腰部"时显示
```

### 3.3 计分规则

**功能评估计分（0-4分/题）**
- 0 = 无困难/不影响
- 1 = 轻微困难/轻微影响
- 2 = 中等困难/有时影响
- 3 = 严重困难/经常影响
- 4 = 无法完成/无法入睡

**付费意愿计分（1-5分）**
- 用于后续转化漏斗分析和用户价值分层

## 四、个性化推荐策略

### 4.1 按层级推荐

| 层级 | 推荐动作类型 | 动作数量 | 转化策略 |
|------|-------------|---------|---------|
| L0 | 预防性体态动作 | 2-3个 | 引导体态改善专题 |
| L1 | 低强度保守动作 | 3-4个 | 3-5天后引导进阶 |
| L2 | 结构化进阶方案 | 4-5个 | 展示阶段目标 |
| L3 | 标准康复动作包 | 4-5个 | 直接推荐+埋点 |
| L4 | 不推荐自行练习 | 0个 | 引导线下评估预约 |
| L5 | 术后专用方案 | 需额外确认手术类型 | 渐进式进阶 |
| L6 | 禁止自行练习 | 0个 | 提供就医指南 |

### 4.2 按恢复目标细化（L0-L3）

**目标=缓解疼痛：**
- 优先：等长收缩、轻柔活动度、呼吸放松
- 避免：负荷性、爆发性动作

**目标=恢复功能：**
- 优先：功能性训练、日常动作模式重建
- 强调：动作质量 > 数量

**目标=回归运动：**
- 优先：稳定性训练、渐进负荷
- 强调：达到功能基准后再恢复运动

**目标=预防复发：**
- 优先：核心/肩胛稳定性、体态改善
- 强调：日常姿势管理习惯

## 五、医学审核说明

### 5.1 红旗症状覆盖

| 红旗类型 | 对应题目 | 触发层级 | 医学依据 |
|---------|---------|---------|---------|
| 马尾综合征 | C4（腰部特有） | L6 | 大小便异常/鞍区麻木/进行性无力 |
| 骨折/脱位 | C5 | L6 | 畸形/严重外伤后剧痛 |
| 感染 | C3+C5 | L6 | 发热+肿胀+疼痛加重 |
| 肿瘤警示 | C3 | L4/L6 | 体重下降+夜间盗汗+休息不缓解 |
| 术后禁忌 | C1 | L6（未许可）/L5（已许可） | 未获许可禁止自行练习 |
| 神经功能障碍 | C2+C5 | L6（无力+高疼痛） | 肌无力/无法主动抬臂 |
| 严重功能丧失 | C5 | L6 | 无法负重/无法主动抬臂 |

### 5.2 免责声明

本问卷**不构成医疗诊断**，仅用于：
- 初步风险评估
- 康复动作适用性筛查
- 引导用户寻求专业医疗建议

所有L6（高风险）和L4（专科评估指征）用户均应被告知：建议咨询专业医生或康复治疗师。
